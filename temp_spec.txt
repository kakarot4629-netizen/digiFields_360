1.  Solution Overview
digiField360 AI is a field service management solution built natively on Salesforce Lightning Platform with no Salesforce Field Service (FSL) licences required. It uses custom objects, Apex invocable actions, Agentforce AI agents, GenAi Prompt Templates, Lightning Web Components, and a React Native offline mobile app connected via Salesforce Hosted MCP Servers.

Environment prerequisites and Salesforce org feature flags
All custom objects, fields, and field-level descriptions
Standard User object custom fields (must be created manually before Apex deploy)
All Apex classes -- purpose, inputs, outputs, side effects, and dependencies

Key internal logic:
Runs SOSL: FIND :searchTerm IN ALL FIELDS RETURNING Knowledge__kav WHERE PublishStatus = "Online" LIMIT 5
Passes knowledge articles + problem description to F360_Troubleshooting prompt template

You are the digiField360 AI Assistant -- a helpful, practical agent for field service

Attribute

Entry Condition (Formula)
AND(ISPICKVAL({!$Record.Status__c}, 'Assigned'), NOT(ISPICKVAL({!$Record__Prior.Status__c}, 'Assigned')), NOT(ISBLANK({!$Record.Assigned_Technician__c})))
Note
The formula ensures this only runs when status CHANGED TO Assigned (not on other updates to an already-Assigned record)


Flow steps:
Step 1: Get Technician Language -- queries User.F360__Preferred_Language__c for the assigned technician
Step 2: Generate AI Briefing -- calls F360_PreJobBriefingAction with workOrderId and language code. The Apex action saves the briefing to AI_Pre_Job_Briefing__c directly inside the action class.
Step 3: Log Task -- creates a Task on the Work Order (Subject: "AI Pre-Job Briefing Generated") for audit trail
